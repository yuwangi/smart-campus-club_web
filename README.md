# 智能社团活动管理系统

这是一个基于 Bootstrap 5 开发的静态 HTML 页面原型，用于演示智能社团活动管理系统的基本流程和界面设计。

> [!IMPORTANT]
> **本项目为纯前端演示项目**
> 所有功能均为静态页面展示或通过 JavaScript 模拟（如登录、注册、数据存储等），不包含后端数据库和服务器交互。
> - **登录/注册**：仅演示界面交互，使用 LocalStorage 模拟登录状态。
> - **数据展示**：所有活动数据、用户信息均为硬编码的静态数据。

## 测试账号

本项目使用 `LocalStorage` 模拟登录状态，您可以使用以下任一方式进入系统：
- **快速登录**：在登录页点击“立即登录”即可（默认账号：`admin`，密码：`123456`）。
- **自主注册**：在注册页输入任意用户名和密码进行注册后登录。

## 页面列表

1.  **登录 (login.html)**: 用户登录界面。
2.  **注册 (regist.html)**: 新用户注册界面。
3.  **首页 (index.html)**: 系统主页，包含活动搜索和活动卡片展示。
4.  **活动详情 (activity.html)**: 展示活动的详细信息，包括海报、时间、介绍等。
5.  **个人中心 (profile.html)**: 用户信息管理，支持修改头像、个人资料等。
6.  **发布活动 (publish.html)**: 活动发布页面，包含 **AI 智能生成** 功能演示（文字生成和海报生成切换）。
7.  **历史记录 (history.html)**: 查看已参加的活动历史。
8.  **活动推荐 (recommend.html)**: 根据用户兴趣推荐的活动列表。

## 使用说明

1.  直接在浏览器中打开 `index.html` 或 `login.html` 即可开始浏览。
2.  页面主要依赖 Bootstrap 5 CDN，请确保网络连接正常以加载样式和脚本。
3.  **发布活动页面** (`publish.html`) 中的 "智能生成" 按钮和 "本地/AI" 切换按钮为界面演示，点击单选框可查看 UI 变化效果。

## 设计风格

-   使用 Bootstrap 5 默认风格，简洁大方。
-   主色调为 Bootstrap Primary Blue。
-   页面间通过超链接实现逻辑跳转。
